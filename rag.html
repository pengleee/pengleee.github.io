End-to-end retrieval-augmented generation

A web application that answers questions from a user’s own documents and shows which documents each answer draws on.

Overview

Course
DSAN 5800 Advanced NLP, Georgetown University, Fall 2024
Team
With Yuting Fan and Yiwei Qi
Materials

RepositoryProject report

System

  • Retrieval — documents and queries embedded with SentenceTransformers (all-MiniLM-L6-v2) and searched with a flat FAISS index.
  • Reranking — candidates reordered by a cross-encoder (ms-marco-MiniLM-L-12-v2).
  • Generation — retrieved passages concatenated with the query and passed to an OpenAI chat model chosen by the user.
  • Interface — Streamlit chat with document upload, immediate indexing of new documents, and source attribution for each answer.

Evaluation and its limits

The team tested robustness — file types, file sizes up to memory limits, empty and corrupted files, invalid queries — and compared two generation models by manual inspection of accuracy and relevance. Retrieval quality was not measured against labelled relevance judgments, and answer faithfulness to the retrieved evidence was not scored separately.

Those two gaps are what I would address next: compare embedding retrieval with a lexical baseline such as BM25 on labelled queries, and check whether each claim in an answer is supported by a retrieved passage. Fluent output alone does not show that either stage worked.
