Semantic search & RAG

SentenceTransformers · FAISS · Information retrieval

This project focuses on semantic search and retrieval-augmented generation: representing documents for retrieval, selecting relevant evidence, and connecting that evidence to generated answers.

Methodological focus

The technical focus is sentence embeddings with SentenceTransformers and similarity search with FAISS. The questions extend beyond finding nearby vectors: what makes a retrieved passage relevant, and does it actually support the answer produced from it?

Evaluation questions

  • How does embedding-based retrieval compare with a lexical baseline?
  • Which useful passages are missed, and which superficially similar passages are retrieved?
  • Can the generated answer be traced back to the retrieved evidence?

Retrieval quality and answer support need separate evaluation. Fluent generation alone does not establish that either stage worked well.

This page describes the project focus. It does not report a completed deployment or verified performance results.
