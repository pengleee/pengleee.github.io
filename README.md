# Peng Li — academic portfolio

A text-first, dependency-free GitHub Pages site. Edit the HTML pages directly; shared appearance lives in `styles.css`.

## Preview and checks

```sh
python3 -m http.server 4173 --bind 127.0.0.1
node tests/site.test.mjs
```

Primary pages: Home, Research, Current Work, Projects, Writing, and About / CV. The CV is an HTML overview with print support. Georgetown is described as graduate coursework in Data Science & Analytics, 2024–2026, not a completed degree.

Only three selected project topics are featured. Do not invent results, dataset details, publication claims, or repository links. Retired teaching and documentary pages have been removed. `life.html` retains a route to Writing for older links.
